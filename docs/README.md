# RaceDay Event Management System - Documentation Directory

This directory contains the complete structural and architectural design documentation for the RaceDay API (PROG6212 POE Part 1).

## Included Artifacts

1. **`ERD_Diagram.png` / `ERD_Documentation.md`**
   - Complete Entity-Relationship Diagram and table definitions.
2. **`API_Endpoint_Plan.md`**
   - Master RESTful API Endpoint Table specifying routes, HTTP methods, roles, request bodies, and expected status codes.
3. **`RaceDay_Database.sql`**
   - Executable T-SQL script containing all table creation DDL, foreign key constraints, analytical views, and seed data.
